Edge Impulse - Bring your own model: lof.tflite
============================================================

Model: int8 (full integer), 7648 bytes, input shape (1, 1), output shape (1, 1).

Upload (Edge Impulse Studio, new project -> upload your model /
"Bring your own model"; menu names can differ between Studio versions):
  - Model file: lof.tflite
  - Model input: other (raw features, not an image or audio)
  - Model output: regression (one value: the anomaly score)
  - Representative features, if asked: lof_representative.npy
  - The model is already int8-quantized. Send float features; Edge
    Impulse quantizes them with the model's own input parameters
    (scale 0.193725, zero point -112) and
    dequantizes the score (scale 0.00770905, zero point -128).

Input - 1 values, in this order:
   1. VALUE

Values are raw, as measured - the normalization is built into the model.
Trained for measured values within (outside, the score is not reliable):
  VALUE: -3.05 .. 46.35

Output: anomaly score (0 = most normal, can exceed 1); anomalous when score > 0.5.

Check - these inputs should give these scores (+- a few hundredths):
  [21.7] -> 0.285 (normal)
  [16.4] -> 0.262 (normal)
  [12.4] -> 0.254 (normal)
  [11.8] -> 0.247 (normal)
  [20.6] -> 0.270 (normal)
  [23.4] -> 0.301 (normal)
  [34.1] -> 0.910 (anomaly)
  [10.3] -> 1.010 (anomaly)
